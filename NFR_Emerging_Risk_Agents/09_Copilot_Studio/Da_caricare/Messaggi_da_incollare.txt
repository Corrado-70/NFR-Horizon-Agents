=== T1.2 - opzione 1, esperienza standard con il code interpreter (allegati: Input_A1_2026Q4.txt e precontrollo_nfr.txt) ===
Esegui il ciclo con l'allegato Input_A1_2026Q4.txt. Prima di consegnare fai il precontrollo con il code interpreter:
1. scrivi l'output JSON completo nel file A1_2026Q4.json (solo il JSON, UTF-8);
2. esegui il file allegato precontrollo_nfr.txt cosi' com'e', come script Python, senza riscriverlo ne' imitarlo: python precontrollo_nfr.txt A1_2026Q4.json Input_A1_2026Q4.txt
3. se la prima riga dell'esito dice "punti da correggere", correggi nel JSON solo i punti elencati nel messaggio dello script, salva lo stesso file e rilancia lo script; al massimo tre giri;
4. consegna A1_2026Q4.json come file scaricabile e, nel messaggio, le prime due righe dell'ultimo esito dello script copiate senza cambiarle, con il numero di giri.
Se lo script non parte, riporta l'errore com'e' e non dichiarare un esito che lo script non ha stampato.
