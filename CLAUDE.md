# Istruzioni per Claude in questo repository

## Rami git

- Si lavora **solo sul ramo `main`**.
- **Non creare rami secondari o paralleli**, compresi quelli `claude/...` delle sessioni remote. L'eccezione e' quando
  l'utente lo dice esplicitamente, oppure quando lo chiedi tu prima e l'utente accetta.
- Se l'ambiente della sessione ti mette d'ufficio su un altro ramo:
  1. passa a `main` prima di modificare qualcosa;
  2. se non puoi, chiedi all'utente come procedere prima di fare commit o push.
- A inizio lavoro: `git fetch` e `git pull` su `main`, per partire dalla versione piu' recente.
- Commit e push solo quando l'utente lo chiede.
